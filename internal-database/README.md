# Обработка строк: выравнивание по ширине

Программа на Visual Prolog, которая читает текстовый файл построчно и выравнивает каждую строку до заданной длины, распределяя пробелы между словами так, чтобы последнее слово оказалось у правого края.

## Задача

Дан текстовый файл. Для каждой строки:
- если в строке несколько слов — равномерно распределить пробелы между словами, чтобы длина стала равна `N` (N ≥ исходной длины);
- если слово одно или строка пустая — добавить пробелы в конец.

## Файлы

- `src/justify_strings.pro` — исходный код
- `data/input.txt` — пример входного файла
- `data/output.txt` — пример результата
- `report.pdf` — отчёт с постановкой, описанием и примерами

## Как устроено

- `process` — запрашивает длину строки, открывает `input.txt` / `output.txt`, запускает обработку.
- `read_and_process/1` — построчное чтение и запись до пустой строки.
- `justify_string/3` — выравнивание одной строки (два случая: несколько слов / одно слово или пустая строка).
- `split_string/2` — разбиение строки на список слов.
- `count_chars/2` — суммарная длина слов.
- `distribute_spaces/3`, `distribute_evenly/5` — равномерное распределение пробелов: базовое количество + остаток по одному в первые промежутки.
- `make_space_block/2`, `assemble_string/2`, `add_spaces_to_end/3` — вспомогательные предикаты.

## Запуск

1. Положить `input.txt` рядом с исполняемым файлом (или использовать `data/input.txt`).
2. Открыть `src/justify_strings.pro` в Visual Prolog, скомпилировать, запустить.
3. Ввести требуемую длину строки — результат появится в `output.txt`.

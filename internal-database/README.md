# Внутренняя база данных Visual Prolog

Две диалоговые программы с внутренней базой данных: опрос о знании языков и магазин игрушек.  
Демонстрируют работу с `database`, `assert`, `retract`, `consult` и `save`.

## Что внутри

### 1. `src/languages_db.pro` — база знаний о языках

- Факты: `language(Lang)` — список языков, `knows(Name, Lang)` — кто каким языком владеет.
- Программа спрашивает имя пользователя и по очереди предлагает языки (y/n), записывая ответы во внутреннюю БД.
- При старте загружает данные из `lang.dba`, при выходе сохраняет обратно.
- В конце выводит сводку: сколько языков знает каждый пользователь.

### 2. `src/toy_store.pro` — магазин игрушек (индивидуальное задание)

- Факты: `toy(Name, Price, AgeMin, AgeMax)` — название, цена, возрастные границы.
- Диалоговое меню: добавить игрушку, удалить, показать все, выйти.
- Девять запросов:
  1. игрушки ≤ 400 руб. для детей 5 лет;
  2. игрушки, подходящие и для 4, и для 10 лет;
  3. цены всех кубиков;
  4. подбор «игрушка (не мяч) + мяч» ≤ 500 руб. для ребёнка 3 лет;
  5. самые дорогие игрушки (±100 руб. от максимума);
  6. игрушки для 1–3 лет дешевле 300 руб.;
  7. игрушки для 7–12 лет;
  8. средняя цена игрушки;
  9. две игрушки для разных возрастов дешевле 800 руб.

## Файлы

- `src/languages_db.pro` — код базы знаний о языках
- `src/toy_store.pro` — код магазина игрушек
- `data/toys.dba` — начальная база данных игрушек (если отсутствует, создаётся при первом запуске)
- `report.pdf` — отчёт с постановкой задачи, описанием и примерами вывода

## Запуск

1. Открыть нужный `.pro` в Visual Prolog.
2. Скомпилировать и запустить.
3. Файлы `lang.dba` / `toys.dba` должны лежать в рабочей директории (рядом с исполняемым файлом).

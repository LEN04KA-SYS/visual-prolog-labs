# Изоморфизм деревьев и упрощение логических формул

Две задачи по рекурсивным структурам данных на Visual Prolog:
1. Проверка изоморфизма бинарных деревьев — с отсечением и без, сравнение деревьев вывода.
2. Упрощение логических формул по аксиомам `true ∨ F = true` и `false ∧ F = false`.

## Файлы

- `src/trees_and_formulas.pro` — **сводная версия**: обе задачи в одном файле, запускается целиком (рекомендуется для демонстрации).
- `src/tree_isomorphism.pro` — отдельный листинг: изоморфизм деревьев с отсечением (соответствует разделу 6.1.2 отчёта).
- `src/formula_simplify.pro` — отдельный листинг: упрощение формул (соответствует разделу 6.2 отчёта).
- `src/graphs.pro` — дополнительно: представление графов (неориентированный и ориентированный взвешенный) тремя способами: факты, список структур, список вершин + список рёбер.
- `report.pdf` — отчёт с постановкой, деревьями вывода и примерами.

> В отчёте также есть версия изоморфизма **без** отсечения (раздел 6.1.1) — она включена в `trees_and_formulas.pro`.

## Задача 1: изоморфизм деревьев

Бинарное дерево: `tree = empty; tr(integer, tree, tree)`.

Два дерева изоморфны, если:
- оба пусты, **или**
- корни равны, а поддеревья изоморфны в прямом порядке (левое↔левое, правое↔правое) **или** в обратном (левое↔правое, правое↔левое).

**Без отсечения** программа находит все пути доказательства: для симметричных листьев — 4 решения.  
**С отсечением** — 1 решение. Отсечение «зелёное»: не меняет декларативный смысл, только убирает лишний перебор.

## Задача 2: упрощение формул

Формула: `formula = true; false; v(symbol); d(formula, formula); c(formula, formula)`,  
где `v` — переменная, `d` — дизъюнкция, `c` — конъюнкция.

Аксиомы:
- `true ∨ F = true`
- `false ∧ F = false`

Программа рекурсивно обходит формулу, применяет аксиомы за один проход и выводит результат в читаемом виде.

## Запуск

1. Открыть `src/trees_and_formulas.pro` в Visual Prolog (или отдельные листинги).
2. Скомпилировать и запустить.

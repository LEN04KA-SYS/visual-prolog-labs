# Рекурсивные структуры данных: операции над множествами

Программа на Visual Prolog, реализующая основные операции над множествами, представленными как списки целых чисел.

## Задача

Множества заданы списками. Реализовать:
- **объединение** `A ∪ B`;
- **пересечение** `A ∩ B`;
- **вычитание** `A \ B` (и `B \ A`);
- **декартово произведение** `A × B` (список пар `pair(X, Y)`).

## Файлы

- `src/set_operations.pro` — исходный код
- `report.pdf` — отчёт с постановкой задачи, описанием и примером вывода

## Как устроено

- `member(X, List)` — проверка принадлежности элемента списку.
- `append(L1, L2, R)` — сцепление списков.
- `add_unique(List, SetA, Current, Result)` — добавление в результат только тех элементов, которых ещё нет.
- `union/3`, `intersection/3`, `subtraction/3`, `cartesian_product/3` — основные операции, реализованные рекурсивно с использованием отсечения для отбрасывания лишних альтернатив.
- `n_element(N, List, X)` — дополнительный предикат: N-й элемент списка (бонус, не входит в базовое задание).

## Запуск

1. Открыть `src/set_operations.pro` в Visual Prolog.
2. Скомпилировать и запустить — программа сама задаёт тестовые множества `A = [5, 7, 13, 14]`, `B = [13, 14, 22]` и выводит результаты.
